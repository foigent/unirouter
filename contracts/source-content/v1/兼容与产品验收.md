## 4. 增量审查要回答什么

UR 审新增 C 授权局部失效、起读/独立游标、canonical身份、策略CAS与实际管理资格、保存/清单提交和字节读取接点；XI 审无B成员、默认拒绝完整grant路径、字节读取的锁/取消、冻结引用与旧恢复兼容、复核全生命周期。双方共同确认 HTTP 元数据头及错误映射可在现有模块实现。

目前没有识别出必须减少覆盖、强制B权限、放宽撤权、扩大外部处理目的地、复制永久正文或增加常驻组件的必要性，因此没有新增用户产品决定。上述候选需原主管增量审查和实现证据；若证据表明必须作这些取舍，再提交准确影响。C0资产完成不解除原UR回归阻塞，也不替代原XI UI整改和旧交付收口。
