# Logs Explorer v2

> **Version**: 2.0  
> **Status**: ✅ 已实现（基于 GPT 咨询 + 团队讨论 + 代码实现）  
> **Last Updated**: 2026-06-29  
> **Priority**: P0（高优先级）

---

## 1. 设计目标

将 Logs 从"日志表格"升级为"调查工作区"。

### 用户场景

| 场景 | 问题 | 调查目标 |
|------|------|----------|
| 1 | 请求失败 | 找原因 |
| 2 | 成本上升 | 找来源 |
| 3 | 延迟上升 | 找瓶颈 |
| 4 | 服务商不稳定 | 找影响 |
| 5 | 审计使用 | 找责任人 |

## 5. 左面板: Investigation Filters

### 筛选器列表

| 筛选器 | 类型 | 选项 |
|--------|------|------|
| 时间范围 | 快捷选择 | 最近 15min / 1h / 24h / 7d / 自定义 |
| 模型 | Multi Select | 从 API 动态获取 |
| 渠道 | Multi Select | 从 API 动态获取 provider |
| 状态码 | Select | 全部 / 2xx / 4xx / 5xx / 429 / 502 / 503 |
| 延迟范围 | Range Slider | 0-100ms / 100-500ms / 500-1000ms / 1000ms+ |

### 交互

- 筛选器变更即时刷新结果（debounce 300ms）
- URL 参数同步（可分享筛选条件）
- 筛选器可折叠（移动端友好）

---

## 6. 中面板: Results

### 表格列

| 列 | 格式 | 说明 |
|----|------|------|
| Request ID | monospace + 复制按钮 | 可点击跳转详情 |
| 模型 | 文本 | 模型名称 |
| 渠道 | Tag | 渠道名称 |
| 状态码 | Tag 着色 | 2xx 绿 / 4xx 橙 / 5xx 红 |
| 延迟 | 数字 + ms | 超过 1000ms 橙色高亮 |
| Token | 数字 | 总 token 数 |
| 费用 | ¥ 金额 | 格式化显示 |
| 时间 | 相对时间 | 最近 24h 内显示"X 分钟前"，否则绝对时间 |

### 分页

- 每页 50 条
- 支持翻页

---

## 7. 右面板: Details

### 触发方式

- 点击表格行展开右侧详情面板

### 内容分区

| 区域 | 内容 |
|------|------|
| 基本信息 | Request ID, 模型, 渠道, 用户, 时间 |
| 性能 | 延迟, Token 用量, 费用 |
| 错误 | Error Code, Error Message（如有） |
| 请求 | Headers, Body（如有） |
| 响应 | Status Code, Body（如有） |

### 交互

- 详情面板可关闭
- 关闭后表格占满宽度
- 支持复制单个字段
