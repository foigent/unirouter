# 无到期限制安装包准备 — 1.14.0

[English](signed-preview-1.14.0.md)

当前源码候选支持明确签名的 v2/never 包；尚未公开发布或分配发布序号。消费者输入故意保留未绑定状态，在网络、Docker 或输出目录操作前拒绝执行。必须先以新源码构建并核对后端、前端和 Linux/Darwin 校验程序，不能把旧 1.13.0 镜像改名充当新版。数据库继续使用 M127。

检查、安装和恢复仍使用原生校验程序，绑定原包哈希和安装计划。旧 v1 包保留原到期时间；包无到期限制也不延长签名授权。交付边界见[安装运行手册](../ops/COMMUNITY-INSTALLER.md)。
