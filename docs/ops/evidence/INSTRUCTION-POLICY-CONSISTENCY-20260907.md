## 主要行为变化与保留的保障

| 情景 | 预期行为 |
|---|---|
| 普通文案或测试修订 | 完成必要修改与验证；不强制设计、升版、部署或创建永久台账 |
| 同一动作已有明确持续授权 | 核对其范围仍适用后继续，不因换命令或阶段重复询问 |
| 新增凭据、Production 动作、付费或删除 | 保留已有明确批准要求；等待期间只暂停依赖步骤 |
| 数据修改涉及 Profile 身份或 Release binding | 仍独立审查精确数据与合同差异，复用既有架构证明，不能一概免审 |
| 平台局部修改 | 复用仍有效证据，补受影响验证；当前已承诺的逐模型验收不被取消 |
| 只完成某个阶段 | 当前请求仍有已授权且未阻塞的必要工作时继续，不以阶段报告代替整体完成 |
| 旧实现被替代 | 分别验收新路径、迁移和退役，依据实际消费者与退出条件；不机械追求净删行数 |
| 缺少退役所需运行证据 | 只阻塞依赖该判断的移除，不声称零消费者，也不取消历史读取或回滚承诺 |
| 阅读 Baseline 草案或旧 PRD | 根据批准状态与适用范围判断；草案不自动形成新承诺，已明确接受的要求不因此失效 |
| Documents 成品达到内容与布局要求 | 必要渲染、逐页检查和缺陷修复后交付；不因无收益的审美迭代无限延迟 |

这是规则语义和真实脚本测试覆盖的预期行为，不把这张表冒充长期模型行为实验。
